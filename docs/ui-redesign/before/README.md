# Flutter reference baseline

These synthetic Health Overview captures were generated before the UI edits, from initial commit `5ec6340d0b06e4cdfdfce38c63a1bd33c8cc76fb`.

- Windows Flutter 3.47.5 widget-test engine; logical viewport 393 × 852.
- Test-only Noto Sans SC plus the existing app icon fonts were loaded.
- The original capture wrapper had no bottom navigation; the After goldens include the newly shared navigation. These are not identical-shell controlled experiments.
- No Apple system font binaries, real health data, iOS Simulator, or physical iPhone evidence.

Current After goldens and their tests are in `mobile/test/`. The old temporary baseline rewrite switch was removed after capture to prevent overwriting this historical evidence from the redesigned implementation.
