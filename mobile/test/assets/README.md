# Golden-test font

Noto Sans SC is a test-only font; it is not declared as a Flutter app asset and does not replace the iOS system font.

- Source: https://github.com/google/fonts/tree/a85815a42757630ce188fdad368c2dfc444d4773/ofl/notosanssc
- Original file: `NotoSansSC[wght].ttf`, downloaded unmodified as `NotoSansSC.ttf`.
- SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`.
- License: accompanying `OFL.txt` (SIL Open Font License 1.1).

This gives Chinese text a readable, reproducible test face without committing licensed Apple or Windows fonts. Flutter widget-test captures are not iOS Simulator or physical iPhone screenshots.
